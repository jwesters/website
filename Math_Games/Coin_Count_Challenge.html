How to Play

Example

You have 20 coins made up of nickels and dimes. Their total value is $1.40. How many of each coin do you have?

Use the total number of coins and the total value to figure out how many of each coin there are.

  • Easy: 2 different coin types.
  • Hard: 3 coin types and an extra clue.
  • Extreme: 4 coin types and enough clues to make the answer unique.

Type a whole number for every coin and press Check Answer. You will see the correct answer immediately. The Tutor is available during every question.

Coin Puzzle Tutor

Example: 20 nickels and dimes worth $1.40

There are 20 coins total. They are nickels (5¢) and dimes (10¢). Together they are worth 140¢.

Practical method

  1. Start with all 20 coins as nickels: 20 × 5¢ = 100¢.
  2. You need 40¢ more.
  3. Changing one nickel into one dime adds 5¢.
  4. 40 ÷ 5 = 8, so change 8 nickels into dimes.
  5. That gives 12 nickels and 8 dimes.

Algebra method

n + d = 20
5n + 10d = 140

From the first equation, n = 20 − d. Substitute that into the value equation and solve for d.

5(20 − d) + 10d = 140
100 + 5d = 140
d = 8, so n = 12

Example: 18 nickels, dimes and quarters worth $2.25

Clue: The number of dimes is 1 greater than the number of nickels.

Practical method

  1. Use the clue first. Try pairs where dimes are exactly one more than nickels.
  2. For each pair, the remaining coins must be quarters so the total count stays 18.
  3. Check the value. The combination that reaches exactly 225¢ is the answer.
  4. The solution is 6 nickels, 7 dimes and 5 quarters.

Algebra method

n + d + q = 18
5n + 10d + 25q = 225
d = n + 1

Use the clue to replace d with n + 1. Then use the coin-count equation to write q in terms of n. Substitute into the value equation and solve.

Example: 14 pennies, nickels, dimes and quarters worth $1.05

Clues: The number of pennies is 1 greater than the number of nickels, and the number of nickels is 2 greater than the number of quarters.

Practical method

  1. Build combinations that obey both clues before checking money.
  2. Every time you choose a quarter count, the nickel count is fixed by the second clue.
  3. That fixes the penny count using the first clue.
  4. The dime count is whatever is needed to reach 14 coins.
  5. Check the total value. The solution is 5 pennies, 4 nickels, 3 dimes and 2 quarters.

Algebra method

p + n + d + q = 14
p + 5n + 10d + 25q = 105
p = n + 1
n = q + 2

Use the clue equations to replace variables until the count and value equations contain only one unknown. Solve it, then work backward.
