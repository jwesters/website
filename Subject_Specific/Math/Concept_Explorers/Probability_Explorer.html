Probability help

What is probability?

Probability is how likely an event is to happen. For equally likely outcomes, probability = favourable outcomes ÷ total possible outcomes.

Independent events

The first event does not change the probability of the next. Examples: rolling a die twice, flipping a coin twice, or replacing a marble between draws.

P(A and B) = P(A) × P(B)

Dependent events

The first event can change the probability of the next. Examples: drawing cards or marbles without replacing them.

P(A and B) = P(A) × P(B | A)

Fractions, decimals, percentages

Reduce fractions by dividing the numerator and denominator by their greatest common factor (GCF). Divide numerator by denominator for the decimal; multiply the decimal by 100 for the percentage.

What is a tree diagram?

A tree shows possible branches for each event. Multiply probabilities along a path. Add the probabilities of different successful paths when a question asks for more than one possible sequence.

What is an area model?

The width represents the first probability. The height of a section represents the next conditional probability. The intersection area is the probability of both events.

How to use this app

Select an experiment, choose 2–5 target events and whether objects are replaced (when available). Run a physical-style trial, inspect exact theoretical probability, switch calculation views, and run simulations. Lessons and practice are in the top navigation.
