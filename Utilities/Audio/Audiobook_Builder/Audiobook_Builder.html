How Audiobook Builder works

Your audio stays on this device.

  1. Add all chapter files. They are naturally sorted by filename when added.
  2. Rename or reorder chapters. Each source file becomes one chapter marker.
  3. Add book metadata and optional JPG/PNG cover art.
  4. Choose bitrate, mono/stereo, normalization, and the silence inserted between chapters.
  5. Select Build M4B. Processing happens locally. Fast mode is recommended for most books.
Encoding note: On an HTTPS website, Audiobook Builder also has a low-level MP3 frame decoder for MP3s that decodeAudioData() rejects. For output it prefers AAC-LC for smaller files; if AAC is unavailable or fails, it automatically retries with its built-in Apple IMA4 encoder. No source audio is uploaded.
Speed: Fast mode pre-decodes the next chapter while encoding the current chapter and uses native resampling where practical. Large chapters automatically switch back to the lower-memory path.
