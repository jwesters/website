# Artwork Library

**Release date: October 18, 2026**

The studio bundles offline artwork for game characters, animals, vehicles, food, furniture, tools, buildings, scenery, collectibles, and user-interface elements. It includes transparent PNG illustrations and searchable SVG assets, with several palettes and appearances for some subjects.

The generator can select supported artwork in response to prompts about characters or scenery. For example, you can request an animal appearance for the player or enemies in engines that support character substitution. A scenery asset is visual decoration unless the game engine provides collision or interaction mechanics for it.

The main UI hides the asset-browser button to keep game creation prompt-focused. Bundled artwork remains available to the generation and ZIP export systems. Selected assets are included in exported games; the complete library is not copied into every game export.

Some icons incorporate Font Awesome Free artwork under CC BY 4.0. Licensing and attribution are documented in **THIRD_PARTY_ASSET_CREDITS.txt**. Artwork quality and support differ among game engines.
