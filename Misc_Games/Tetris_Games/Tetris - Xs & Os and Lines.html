Objectives

•The game randomly asks you to clear 1–5 Lines or 1–5 X/O Matches.
•During a Lines goal, only completely filled horizontal rows clear. X/O matches stay on the board.
•During an X/O goal, make 5 or more identical symbols in a straight horizontal, vertical, or diagonal line. Only those matching cells clear.
•Separate matches created at the same time each count toward the goal.
•Finish the current target and a new random objective appears.
